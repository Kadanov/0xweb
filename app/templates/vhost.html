Virtual Host Enumeration

The server routes on the Host header. The default host serves this lab; internal virtual hosts serve something else.

curl -s http://127.0.0.1:8000/ -H "Host: dev.0xweb.local"
curl -s http://127.0.0.1:8000/ -H "Host: admin.0xweb.local"

Level 3's hostname is not guessable — it leaks in a config file you must find via another category first.

Tools: ffuf -H "Host: FUZZ.0xweb.local", gobuster vhost.
